# Linux and Cybersecurity Scripts

This directory contains scripts developed during my Linux and cybersecurity learning journey.

## Planned Projects

### 1. System Information Script
A Bash script that displays basic system information, including the operating system, kernel version, uptime, memory usage, and disk space.

### 2. Disk Usage Checker
A script that reports disk usage and helps identify filesystems that are running low on available space.

### 3. Log Summary Tool
A script that summarizes selected system log information for learning and troubleshooting.

### 4. File Organization Tool
A script that organizes files according to defined rules, using safe handling and clear output.

## Development Principles

- Understand every command before using it in a script.
- Test scripts in a controlled environment.
- Handle errors and unexpected input.
- Avoid destructive actions without safeguards.
- Document the purpose, usage, and limitations of each script.

## Current Status

These projects are planned. Scripts will be added as I learn the necessary Linux commands and Bash scripting concepts.
