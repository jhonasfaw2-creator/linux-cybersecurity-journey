# Day 9 — Linux System Logs

## Objective
Learn how to inspect Linux logs and identify system events.

## Key Commands
- `journalctl` — View system logs.
- `journalctl -b` — Current boot logs.
- `journalctl -p err` — Error messages.
- `journalctl -n 20` — Latest 20 entries.
- `ls /var/log` — Explore log files.

## Cybersecurity Importance
System logs help investigate errors, authentication activity, and unusual system behavior.

## What I Learned
I learned how to inspect Linux logs and use them for basic troubleshooting and security investigation.
