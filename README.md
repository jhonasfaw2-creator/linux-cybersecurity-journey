# Linux Cybersecurity Journey

## About This Project

This repository documents my hands-on journey
learning Linux and developing practical cybersecurity skills.

My goal is to understand the Linux operating system,
practice through controlled labs, solve problems,
and build useful projects.

## Learning Areas

- Linux fundamentals and command-line usage
- Filesystem navigation and file management
- Users, groups, and permissions
- Bash scripting and automation
- Processes, services, and system monitoring
- Networking and security fundamentals
- Linux hardening and log investigation

## Daily Practice

Each learning session includes:
- Video lessons and reading assignments
- Practical exercises
- Independent challenges
- Troubleshooting notes
- Knowledge checks
- Documented results

## Repository Structure

- daily-notes/ - Learning notes and reflections
- labs/ - Practical exercises
- scripts/ - Tools and automation
- posts/ - Learning-in-public drafts
- resources/ - References and study materials

## Safety

All security experiments will be performed
on systems I own or have permission to test.
